# MCA 7.7.32 Selective Synchronization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Selectively port high-value MCA `7.7.23–7.7.32` fixes into VillAIgence while preserving persistent NPC identity, Memory 2.0, authoritative context, provider security, supply-chain policy and rollback compatibility.

**Architecture:** Port final upstream subsystem states into focused VillAIgence PRs rather than merging or replaying the complete upstream history. Core data-integrity and navigation packages ship first; operator-authored lore and Context Editor ship second; client/service compatibility remains isolated. Every package starts with regression tests, records exact upstream SHAs and has an independent automated and live acceptance gate.

**Tech Stack:** Java 21, Minecraft 1.21.1, MCA-derived common module, Fabric, NeoForge, JUnit 5, Gson, Gradle, GitHub Actions, world-local JSON persistence.

## Global Constraints

- Implementation base is VillAIgence `1.21.1` at or after `521568f903078b91dd5817cdc9a551bd2392e663`.
- Upstream audit target is `Luke100000/minecraft-comes-alive@c3f92f1f7d6f745ab885dcfed350b4e60e1b8cbc`.
- Common ancestor is MCA `7.7.22` commit `a3de832505fcc6a9c4649bfbc0260beb6f0740c4`.
- Do not merge `Luke100000:1.21.1` into VillAIgence.
- Do not blindly cherry-pick mixed or intermediate upstream commits.
- Do not replace VillAIgence `OpenAIChatAI` transport, parser, retry, endpoint or diagnostic behavior.
- Do not import upstream `.github/workflows/**`, `scripts/**`, Gradle wrapper, verification metadata or lockfiles.
- LLM output remains non-authoritative and server mutations remain validated/revalidated.
- NPC UUID, memory, semantic knowledge, relationships, events and voice identity must survive conversion.
- Operator-authored lore is not `SYSTEM_OBSERVED`, semantic FACT or dialogue.
- New persistent data is world-local, versioned, atomic, bounded and fail-soft.
- Common, Fabric, NeoForge and repository-security checks are mandatory before merge.
- Each implementation task is delivered as a separate PR unless explicitly grouped by the release gate.
- Preserve `0.1.15+1.21.1` JAR SHA-256 `af142be94885541bb4840d0effff73627afe3f0e245dec8307ed665701cc94fb` as rollback evidence.
