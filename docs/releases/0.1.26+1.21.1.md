# VillAIgence 0.1.26

Vill-AI-gence — Giving villagers a mind of their own.

This release promotes the post-`0.1.25` reliability, voice, concurrency and automated-acceptance work.

## Included runtime behavior

- preserves one authoritative NPC identity across tombstone replay, transport, resurrection and restart;
- rejects a conflicting stored UUID without consuming the portable grave data;
- recovers malformed auxiliary JSON stores by preserving corrupt bytes, regenerating valid canonical state and leaving healthy sibling stores unchanged;
- routes text turns through an authenticated server-resolved player/NPC session with exactly-once response and persistence effects;
- isolates Operator Lore responses by authenticated session and preserves explicit stale-revision conflict/retry behavior;
- retains one monotonic deadline across voice queue handoff, STT, Chat retries and optional TTS;
- retains navigation and gameplay corrections for water escape, ladders, obstacles, closed doors, gifts, fishing and mounted archers.

## Automated release assurance

The exact candidate passed:

- repository security and supply-chain policy;
- common/unit and deterministic mock-provider tests;
- sixteen required Fabric server GameTests;
- Fabric and NeoForge builds;
- exact production Fabric startup, controlled stop/save and same-world restart;
- real death → grave → portable data → resurrection lifecycle evidence;
- six-case destructive persistence-recovery matrix;
- real Simple Voice Chat Opus encode/decode, loss/order and resource-lifecycle evidence;
- five production JVM cycles under a 512 MiB heap with stable hashes for all six canonical stores;
- distributable package smoke and byte-for-byte identity between the production-accepted and packaged JAR.

The release workflow uses no paid provider and no repository secret for these acceptance scenarios.

## Runtime

- Minecraft 1.21.1
- Fabric Loader
- Java 21
- Fabric API for Minecraft 1.21.1
- Simple Voice Chat 2.6.20 or newer

VillAIgence intentionally retains MCA's internal mod ID `mca`. Remove the original MCA Reborn JAR before installing VillAIgence; do not install both simultaneously.

Server configuration remains `config/livingworld.json`. API credentials stay server-side. Back up the world and `<world>/livingworld/` before installing the release.
