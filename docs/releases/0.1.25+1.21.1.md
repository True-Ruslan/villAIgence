# VillAIgence 0.1.25

Vill-AI-gence — Giving villagers a mind of their own.

This release is the first VillAIgence artifact promoted through the complete exact-production release gate introduced after `0.1.24+1.21.1` had already been published.

## Included runtime behavior

- preserves MCA custom inventory when a valid tombstone captures an NPC;
- avoids loose duplicate inventory drops after successful tombstone capture;
- retains the legacy single loose-drop fallback when no tombstone accepts the NPC;
- preserves UUID, name and stored inventory through grave transport and resurrection;
- retains the existing AI, voice, Memory 2.0, Operator Lore and synchronized MCA behavior.

## Exact release assurance

Before publication, the attached JAR must pass:

- repository security policy;
- production Fabric startup, clean shutdown and same-world restart in two JVMs;
- canonical persistent-store validation and restart hashes;
- acceptance risk catalog and server GameTests;
- Fabric and NeoForge builds;
- distributable package verification;
- byte-for-byte identity between the production-accepted JAR and the published JAR.

## Runtime

- Minecraft 1.21.1
- Fabric Loader
- Java 21
- Fabric API for Minecraft 1.21.1
- Simple Voice Chat 2.6.20 or newer

VillAIgence intentionally retains MCA's internal mod ID `mca`. Remove the original MCA Reborn JAR before installing VillAIgence; do not install both simultaneously.

Server configuration remains `config/livingworld.json`. API credentials stay server-side.

Back up the world before installation or update. The official JAR still requires the focused installed tombstone-inventory canary documented in `docs/livingworld/VALIDATION_0.1.25_RELEASE_GATE.md`.
