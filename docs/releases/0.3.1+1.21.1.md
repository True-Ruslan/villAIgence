# VillAIgence 0.3.1

Vill-AI-gence — Giving villagers a mind of their own.

`0.3.1+1.21.1` is a narrow corrective release over immutable `0.3.0+1.21.1`. It fixes the installed crowded-history Memory 2.0 recall defect found during `VAI-PCM-MULTI-001` acceptance without widening prompt windows, changing persistence, or weakening NPC/player isolation.

## Fixed

- Older eligible `PLAYER_TOLD` dialogue that is still retained can be recovered for a targeted question even after more than 32 newer eligible events have pushed it outside the recency lane.
- Query relevance is deterministic and server-owned, and is evaluated only inside the already eligible NPC/player event set before the existing bounded candidate merge.
- The hard Memory 2.0 prompt bounds remain unchanged: at most 32 candidates enter the final ranking path and at most 6 results reach episodic/social prompt context.
- Text chat now persists the current player message and captures its immutable world/memory snapshot on the server thread before asynchronous provider work, so the current utterance drives the same bounded query-aware retrieval without off-thread mutable-state reads.

## Unchanged boundaries

This patch adds no:

- persistence schema/version change or migration;
- public configuration change;
- provider request/schema/call-count change;
- semantic/vector database or embedding retrieval;
- larger prompt or memory candidate windows;
- proximity-only NPC voice retargeting behavior.

Existing current-fact authority, FACT/BELIEF semantics, NPC/player privacy eligibility, social graph authority, relationship mutation authority and server-owned gameplay validation remain unchanged.
